# Daño hepático por alcohol

- **Daño hepático producido por el alcohol**
    
    El daño empieza con fibrosis pericentral (vena central) → Cirrosis micronodular → Cirrosis macronodular
    
    El alcohol o etanol, se metaboliza por ***OH deshidrogenasa y CYP450 a* acetaldehido** que daña el hígado
    
    ***Alcohol deshidrogenasa:*** actúa en citosol hepático y un poco en estómago. No es inducible, se satura rápido. Mujeres tienen menos que hombres.
    
    ***Sistema microsomal hepático*** (CYP450): sistema inducible, genera tolerancia, se adapta. El problema es que otras drogas comparten esta vía.
    
    **Fisiopatología**
    
    Ingesta crónica de alcohol (hombres >60 g/día, mujeres >40g/día) 
    
    → Formación de acetaldehido → **Estímulo de célula estrellada** → Síntesis de col
    
    → Aumento de peroxidación de lípidos → aductos proteícos →Estimula célula estrellada → autoanticuerpos
    
    → Aumento de permeabilidad del intestino → traslocación bacteriana → aumento endotelinas → macrófagos (Kupffer) estimula inflamación → Estimula célula estrellada
